# Игровой сервер RAGE MP с чистой архитектурой (Node.js / Vue 3 / Sequelize / Redis)

![CI](https://github.com/akak1y/RAGEMP_server/actions/workflows/ci.yml/badge.svg)
![License](https://img.shields.io/github/license/akak1y/RAGEMP_server)

Каркас игрового сервера для **RAGE Multiplayer (GTA V)**. Проект построен на современном стеке и решает типичные боли платформы: зависание HUD, конфликты клавиш с чатом, лишняя нагрузка на БД и «спагетти-код» без слоёв.

---

## 🛠 Стек технологий

* **Бэкенд:** Node.js, RAGE MP API
* **База данных (ORM):** MySQL + **Sequelize ORM** — никаких «сырых SQL строками»
* **Кэширование:** **Redis** — хранение в ОЗУ для разгрузки MySQL
* **Интерфейсы (CEF):** Vue 3 (Composition API, Vite), архитектура SPA — одно браузерное окно на всю игру
* **Веб-админка:** WebSocket + JWT, live-таблицы и карта игроков (Leaflet)
* **Тесты:** Jest — сервер и клиент (глобальный мок `mp.*` API), CI на GitHub Actions
* **Логи и замеры:** кастомный async-логгер + `perf_hooks` для профилирования

---

## 📊 Производительность

| Операция | MySQL | Redis | Эффект |
|---|---|---|---|
| Проверка игрока (`/checkban`) | ~12–15 мс | ~0.004 мс | **~x3000 быстрее** |
| Счётчик аккаунтов для HUD | `COUNT(*)` на каждый запрос | `INCR` при регистрации | ноль тяжёлых запросов в игре |
| Списание денег | атомарный `UPDATE` с проверкой баланса | — | нет race condition |
| Позиция игрока | запись только при выходе | — | ноль нагрузки на диск в сессии |

Тайминги можно увидеть прямо в игре: `/checkban [логин]` и `/bench` выводят время ответа MySQL и Redis.

## 🏗 Архитектура: 4 слоя

![Архитектурный граф зависимостей](docs/architecture-graph.png)

* **Контроллеры** — тонкие обработчики событий RAGE MP и команд
* **Сервисы** — бизнес-логика: деньги, транспорт, тюнинг, инвентарь, курьер, аудит
* **Модели** — Sequelize с ленивой инициализацией
* **Middleware** — проверки прав, rate-limiting, error boundary
* **Core** — db, redis, logger, profiler

Подробный разбор слоёв, паттернов и решений — в [docs/architecture.md](docs/architecture.md).

## 🎮 Ключевые фичи

* **Тюнинг транспорта (LSC)** — серверные цены, бинарная система «купил / не купил», синхронизация между игроками через DataHandler'ы; визуал применяется только после подтверждения сервера (server-authoritative).
* **Топливо и заправка** — серверный расход по скорости, глушение на нуле, сохранение при деспауне, заправка на станции с оплатой за фактические литры.
* **Работа «Курьер»** — стейт-машина заказов (pickup → delivery → return), рабочий транспорт, оплата по дистанции, античит по минимальному времени доставки.
* **Веб-админка** — JWT-логин, live-таблицы БД, карта игроков с иконками локаций из `config.js`, schema-driven формы создания строк; каждое действие — в аудит.
* **Транзакции** — все финансовые операции «всё или ничего»: покупка авто, тюнинг, заправка, `/pay`.
* **Rate-limiting** — Redis-счётчики с коалесценцией нарушений в аудит (одна строка на серию); fail open при падении Redis.
* **UX** — защита чата от конфликтов клавиш, заморозка персонажа при открытом UI, фокус-трап с ESC.
* **Аудит** — журнал бизнес-событий: кто, что, когда, с какой позиции и IP.

## 🚀 Установка и запуск

```bash
# 1. Бэкенд
cd packages/main
npm install

# 2. Фронтенд (в отдельном терминале)
cd UI-Server
npm install
npm run dev   # Vite на http://localhost:5173
```

**Настройка:**
1. Скопируй `packages/main/settings.example.json` → `settings.json` и замени плейсхолдеры на свои данные (пароли, хосты). **Важно:** `settings.json` уже в `.gitignore` — он не попадёт в репозиторий.
2. Запусти сервер — таблицы создаются автоматически при первом старте.
3. Redis заполнится статистикой аккаунтов при запуске.

**Тесты** (в корне репозитория):
```bash
npm test            # сервер + клиент одним запуском (npm workspaces)
npm run test:server
npm run test:client
```
